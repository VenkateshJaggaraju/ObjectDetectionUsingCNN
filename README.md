# 🧠 Object Detection using CNN

## 🚀 Overview

This project implements an **Object Detection System using Convolutional Neural Networks (CNN)** capable of detecting and classifying **1000+ objects in a single image**. The model leverages deep learning techniques to identify multiple objects with high accuracy in real-time scenarios.

---

## 🎯 Features

* 🔍 Detects **1000+ object categories**
* 🧠 Built using **Convolutional Neural Networks (CNN)**
* 🖼️ Supports detection of **multiple objects in a single image**
* ⚡ Fast and efficient prediction
* 📦 Bounding box generation for detected objects
* 🎯 High accuracy with pre-trained models

---

## 🛠️ Tech Stack

* **Python**

## 🧠 Model Details

* Used **pre-trained CNN models** (like ResNet / YOLO / MobileNet)

## ⚙️ How It Works

1️⃣ Input Image
2️⃣ Preprocessing (resize, normalize)
3️⃣ CNN extracts features
4️⃣ Object detection + classification
5️⃣ Output with bounding boxes and labels

---

## 🧪 Sample Output

* Detected objects with:

  * Label (e.g., person, car, dog)
  * Confidence score
  * Bounding boxes
